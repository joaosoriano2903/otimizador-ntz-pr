# SystemOptimizer v1.1.0

![Logo](assets/logo.png)

**SystemOptimizer** é um otimizador de sistemas desenvolvido pela NTZ que visa aumentar o desempenho do Windows com funções avançadas de limpeza, otimização de CPU, ajustes de rede, desativação de serviços desnecessários, entre outros recursos.

---

## 🔧 Funcionalidades

### Otimização
- Modo de desempenho e modo Ultimate
- Tweaks de CPU (Intel e AMD)
- Ajustes de serviços do Windows
- Otimização de USB e inicialização

### Limpeza
- Limpeza de cache e arquivos temporários
- Desativação de hibernação
- Limpeza de logs do sistema e Windows Update
- Desativa GameDVR e coleta de dados

### Rede
- DNS Cloudflare
- MTU e TCP
- Firewall e Wi-Fi AutoConfig
- Interface com Full Duplex 1G

### Info do Sistema
- Monitoração em tempo real (CPU/RAM)
- Exibe hardware, sistema operacional, bateria, disco e rede

---

## 🚀 Como usar

1. Execute `SystemOptimizer.exe` como administrador.
2. Navegue entre as abas pelo menu lateral:
   - Otimização
   - Limpeza
   - Rede
   - Info Sistema
3. Ative os switches desejados e clique no botão de executar.

---

## 🏠 Instalador

O instalador foi criado com Inno Setup, contendo:
- Caminho padrão: `C:\Program Files\SystemOptimizer`
- Atalho na área de trabalho
- Termo de uso
- Registro de desinstalação
